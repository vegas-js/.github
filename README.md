# Vegas GitHub organization configuration

This repository hosts the public profile and shared community health files for
[Vegas](https://github.com/vegas-js).

- [`profile/README.md`](profile/README.md) appears on the organization's public overview page.
- [`SUPPORT.md`](SUPPORT.md) explains where to get help and report problems.
- [`.github/FUNDING.yml`](.github/FUNDING.yml) specifies the organization's default funding links.

Project-specific contributor guidance, issue forms, pull request templates, and
security reporting instructions are maintained in the
[`vegas-js/vegas`](https://github.com/vegas-js/vegas) repository.

For bugs or feature requests, use the
[Vegas issue forms](https://github.com/vegas-js/vegas/issues/new/choose)
instead of opening an issue in this configuration repository.
