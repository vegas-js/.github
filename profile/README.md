# Vegas

**Vite-powered development and build tooling for Google Apps Script.**

Vegas supports single-page applications and script-only Apps Script projects,
with a Vite-based development workflow, production builds, and a local runtime
for selected Apps Script APIs.

## Get started

- [Documentation and getting started](https://vegasjs.dev/guide/)
- [Source code and contributions](https://github.com/vegas-js/vegas)
- [Report a bug or request a feature](https://github.com/vegas-js/vegas/issues/new/choose)

## Packages

- [`@vegasjs/vegas`](https://www.npmjs.com/package/@vegasjs/vegas) — development and build tool
- [`create-vegas`](https://www.npmjs.com/package/create-vegas) — project scaffolding tool

**Project status:** Vegas is experimental, and breaking changes may occur.
The local runtime implements only selected APIs; it is not a complete or exact
replacement for Google's Apps Script execution environment.

Vegas is an independent open-source project and is not affiliated with
Google LLC or VoidZero Inc.
