# Support

This file provides the default support guidance for repositories in the
[Vegas GitHub organization](https://github.com/vegas-js). Follow a repository's
own support instructions if they are provided.

## Documentation and usage

Start with the [Vegas documentation](https://vegasjs.dev/guide/), including
its [getting started guide](https://vegasjs.dev/guide/) and
[Local Runtime documentation](https://vegasjs.dev/guide/local-runtime).
Check [existing issues](https://github.com/vegas-js/vegas/issues) before filing
a new report.

## Bugs and feature requests

Use the [Vegas issue forms](https://github.com/vegas-js/vegas/issues/new/choose)
for reproducible bugs and feature proposals affecting `@vegasjs/vegas` or
`create-vegas`. Provide relevant versions, a minimal reproduction, and the
behavior you expected. Never include credentials, access tokens, or private
Apps Script project data in public reports.

## Security vulnerabilities

**Do not disclose security vulnerabilities in public issues.** Refer to the
[Vegas security policy](https://github.com/vegas-js/vegas/security/policy)
and use the repository's
[private vulnerability reporting](https://github.com/vegas-js/vegas/security/advisories/new)
process where available.

## Contributing

See the project's [contribution guidelines](https://github.com/vegas-js/vegas/blob/main/CONTRIBUTING.md)
for setup, testing, and pull request expectations.
